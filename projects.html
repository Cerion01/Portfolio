My Projects

Ionic Sleep Tracker

A sleep tracker built with Ionic components in the Angular framework for an interactive mobile experience. HTML, SCSS, and TypeScript were used throughout the project to allow users to log overnight sleep, log sleepiness throughout the day out of a scale of seven, and to view all of their logs on the home page. Data is stored using IndexedDB on the local device.

Interactive Discord Bot

A discord bot created in Python that enchances user engagement in Discord servers with interactive commands. Functionalities include music playback random image retrieval, advice generation, and a gambling simulator that allows for great entertainment. With the music playback (that produces audio from selected youtube videos), an option for local voice recognition allows the local user to enact commands to play music from the microphone instead of typed commands.
